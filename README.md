#  Wireshark Network Analysis Projects

This repository contains a series of practical network analysis projects using **Wireshark**. Each folder below represents a different focus area in protocol-level packet inspection.

---

## 📁 Projects

### 🔹 [HTTP Packet Analysis](./http-traffic/Project%201%20-%20HTTP%20Packet%20Analysis/)
Analyzed HTTP request and response headers to understand basic web communication.

### 🔹 [DNS AAAA Query Analysis](./dns-traffic/DNS%20AAAA%20Query%20Analysis/)
Captured and reviewed DNS queries resolving IPv6 addresses using `AAAA` records.

### 🔹 [TCP 3-Way Handshake Deep Dive](./tcp-analysis/TCP%203-Way%20Handshake%20Deep%20Dive/)
Dissected the TCP connection establishment process using SYN, SYN-ACK, and ACK.

### 🔹 [ICMP Echo Request Analysis](./icmp-analysis/ICMP-Echo-Analysis/)
Inspected ICMP echo requests and replies used in ping operations.

---

## 🛠️ Tools Used

- **Wireshark**: Packet capturing and inspection
- **PCAP Files**: Traffic capture files for offline analysis
- **Kali Linux / Windows**: Operating systems used for capturing and analysis

---

## ✅ Purpose

These projects are part of my Blue Team learning journey. They demonstrate protocol behavior, common traffic patterns, and provide practice with dissecting packets at different OSI layers.
